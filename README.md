## 🚀 About The Project

**Extensio.ai** is an AI-powered platform that allows users to generate Chrome extensions using natural language prompts.

Instead of writing extension code manually, users simply describe what they want, and the platform generates the extension structure automatically, packages it, and makes it ready for download.

This project simplifies browser extension development for beginners, students, and rapid prototyping teams.

## ⚙ Installation

### Clone Repository

```bash
git clone <your-repo-url>
cd extensio-ai
```

### Install Dependencies

```bash
npm install
```

### Configure Environment

Create `.env`

```env
OPENAI_API_KEY=your_api_key_here
PORT=3000
```

### Run Development Server

```bash
npm run dev
```
